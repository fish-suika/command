# COMMAND Phase 2（気持ちよさ）Implementation Plan

> **For agentic workers:** 1人の実装者がこの計画を上から順に実行する。Steps use checkbox (`- [ ]`) syntax.

**Goal:** コンボ倍率・コンボ演出・成功エフェクト・音の作り込み・リザルトの演出を加え、「入力の気持ちよさ」を作る。

**前提（いまの状態）:** Phase 1 完了。制限時間30秒、3クリアごとにコマンドが1個伸びる（最大9）、10連続クリアで +3秒 の時間ゲージ。検証 17/17。
まず `src/` の全ファイルと `docs/superpowers/specs/2026-10-02-command-design.md` を読むこと。

**本人が決めたこと（2026-10-02）:**
- コンボは **段階的な倍率**。ミスで ×1 に戻る
- 難易度は **長さだけ**（WASD 出題・1コマンドごとの制限時間は入れない）

**絶対に守ること（資料§16）:** 演出で次のコマンドを隠さない／見づらくしない。リトライまでの時間を延ばさない。

### Task 1: コンボ倍率（ロジック）

**Files:** `src/10-logic.js`, `src/verify-tests.js`

- [ ] **Step 1: テストを追加する**（verify-tests.js の既存テストの後ろ、結果表示の前）

```js
test('comboMult: COMBO_STEP ごとに COMBO_RATE ずつ上がり、上限で止まる', () => {
  const N = CFG.COMBO_STEP, r = CFG.COMBO_RATE, M = CFG.COMBO_MULT_MAX;
  eq(comboMult(0), 1, '0');
  eq(comboMult(N - 1), 1, 'STEP-1');
  eq(comboMult(N), 1 + r, 'STEP');
  eq(comboMult(N * 2), 1 + r * 2, 'STEP*2');
  eq(comboMult(N * 1000), M, '上限');
});

test('isComboMilestone: 5 と COMBO_STEP の倍数だけ', () => {
  const N = CFG.COMBO_STEP;
  eq(isComboMilestone(0), false, '0');
  eq(isComboMilestone(4), false, '4');
  eq(isComboMilestone(5), true, '5');
  eq(isComboMilestone(N), true, 'STEP');
  eq(isComboMilestone(N + 1), false, 'STEP+1');
  eq(isComboMilestone(N * 3), true, 'STEP*3');
});

test('クリア時の得点にクリア後のコンボの倍率がかかる', () => {
  const s = createState(); press(s, 'U', 0, R0);
  let t = 0;
  for (let c = 0; c < CFG.COMBO_STEP - 1; c++) clearOne(s, () => (t += 10));
  const len = s.command.length, before = s.score;
  clearOne(s, () => (t += 10));
  eq(s.combo, CFG.COMBO_STEP);
  eq(s.score - before, Math.round(clearScore(len) * comboMult(CFG.COMBO_STEP)));
});

test('ミスすると倍率が ×1 に戻る', () => {
  const s = createState(); press(s, 'U', 0, R0);
  let t = 0;
  for (let c = 0; c < CFG.COMBO_STEP; c++) clearOne(s, () => (t += 10));
  press(s, 'D', t += 10, R0); // ミス
  const len = s.command.length, before = s.score;
  clearOne(s, () => (t += 10));
  eq(s.score - before, clearScore(len));
});
```

`clearOne(s, nextT)` は既存の補助関数（Phase 1 の第2回で追加済み）。引数の形が違う場合は、既存の形に合わせてテストの呼び出しを書き換えること（関数自体は変えない）。

- [ ] **Step 2: `src/10-logic.js` を変更する**
  - `CFG` に追加:
    ```js
    COMBO_STEP: 10,      // 何コンボごとに倍率が上がるか
    COMBO_RATE: 0.5,     // 1段あたり上がる倍率
    COMBO_MULT_MAX: 3,   // 倍率の上限
    ```
  - 関数を追加:
    ```js
    function comboMult(combo) {
      return Math.min(1 + CFG.COMBO_RATE * Math.floor(combo / CFG.COMBO_STEP), CFG.COMBO_MULT_MAX);
    }

    // コンボ表示を出す節目: 5 と COMBO_STEP の倍数
    function isComboMilestone(combo) {
      return combo === 5 || (combo > 0 && combo % CFG.COMBO_STEP === 0);
    }
    ```
  - `press()` のクリア処理: **先に** `combo++` と `maxCombo` 更新をしてから、`s.score += Math.round(clearScore(len) * comboMult(s.combo));` にする（いまは score 加算が先なので順序を入れ替える）。
  - `createState()` に `maxMult: 1,  // 到達した最大倍率` を追加し、クリア時に `s.maxMult = Math.max(s.maxMult, comboMult(s.combo))`。

### Task 2: 画面の演出

**Files:** `src/00-head.html`, `src/30-view.js`

演出はすべて CSS アニメーション＋既存の `restartAnim(el, cls)` で作る。**中央のコマンド（#cmd）に重ならない位置**に出すこと。

- [ ] **Step 1: HUD のコンボ倍率**
  - COMBO の数字の横に倍率バッジ `<span id="mult">×1.5</span>` を置く。×1 のときは非表示。
  - 倍率の段（×1.5 / ×2 / ×2.5 / ×3）ごとに色を変える（例: 水色 → 緑 → 黄 → ピンク）。CSS 変数 `--tier-color` を `#app` に設定し、ほかの演出もこの色を使う。
  - 段が上がった瞬間にバッジが弾む（scale 1.6 → 1、0.25秒）。

- [ ] **Step 2: コンボの節目表示**
  - `#stage` 内の **#cmd より上**に `<div id="combo-pop"></div>` を置く（高さを固定して、表示されてもコマンドの位置がずれないようにする）。
  - `isComboMilestone(s.combo)` が真のクリアで `"10 COMBO!"` のように表示し、0.6秒で上へ浮いて消える。文字色は `--tier-color`。30コンボ以上は少し大きく、光彩（text-shadow）を付ける。

- [ ] **Step 3: クリア時のエフェクト**
  - #cmd の後ろに、広がって消える輪（`::before` などの擬似要素か専用 div、`--tier-color`、0.3秒、`pointer-events:none`、z-index は #cmd より下）。
  - SCORE の数字が増えたとき軽く弾む（scale 1.15 → 1、0.12秒）。

- [ ] **Step 4: 高コンボの雰囲気**
  - 倍率が ×2 以上のとき、画面の背景にごく薄い `--tier-color` の放射グラデーションを敷く（不透明度 0.06〜0.1 程度。コマンドの読みやすさを落とさない）。ミスで消える。

- [ ] **Step 5: ミス時**
  - 既存の赤い揺れに加え、コンボが2以上で途切れたときだけ、COMBO の数字が赤く一瞬光る。

- [ ] **Step 6: リザルト**
  - SCORE の数字を 0 から最終値まで **0.5秒** でカウントアップする（`requestAnimationFrame`。RESULT_LOCK 0.6秒の内に終わる）。
  - MAX COMBO の行に到達倍率を添える（例: `42  (×3)`）。

- [ ] **Step 7: ビルドしてコミット** 「Phase2: コンボ演出とクリアエフェクトを追加した」

### Task 3: 音

**Files:** `src/20-snd.js`, `src/95-boot.js`, `src/30-view.js`（必要なら）

- [ ] **Step 1: `Snd` を作り込む**（既存の `beep()` を使う。音量は今と同程度に抑える）
  - `hit(i)`: コマンド内の i 番目（0始まり）ほど少し高く（例 `880 * 2 ** (i / 12)`）。打ち進む感触を出す
  - `clear(tier)`: 倍率の段（0〜4）が上がるほど高い／和音を重ねる
  - `milestone()`: 節目表示に合わせた明るい3音
  - `tick()`: 残り5秒〜1秒の各秒で短いクリック音（ループで秒の切り替わりを検出。時間延長で残りが増えたときに二重に鳴らさない）
  - `miss()` / `boost()` / `end()` は既存のまま（end は結果発表らしく少し長くしてもよい）
- [ ] **Step 2: `95-boot.js` で呼び分ける**。boost と節目が同時のときは boost を優先し、節目の音は重ねない。
