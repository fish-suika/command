## 1. ゲーム概要

制限時間内に、画面に出る矢印コマンドを速く正確に入力し続けるスコアアタック。
1プレイは短く、ミスしても続けられ、終わったらすぐ再挑戦できる。「あと1回だけ」と思わせることがゴール。

優先順位は **入力の気持ちよさ ＞ テンポ ＞ 分かりやすさ ＞ リトライの速さ ＞ 機能の数**。

## 2. 技術方針

- 素の JavaScript ＋ HTML/CSS。フレームワーク・three.js は使わない
- 矢印は DOM の文字として表示する。演出は CSS アニメーション
- 画像・音声ファイルはゼロ（音は Web Audio の波形合成）
- 前2作と同じく `src/` の分割ソースを `build.sh` で1枚の HTML に結合する
  - 出力: `command.html` と `index.html`（GitHub Pages 用のコピー）
  - 検証ページ: `verify.html`（ロジックのみを結合）
- 対応端末: **PC（キーボード）＋スマホ（タッチ）**。縦持ち・横持ちどちらでも遊べる

## 4. 状態

```
state = {
  phase: 'ready' | 'playing' | 'result',
  timeLeft,        // ミリ秒
  score,
  combo,           // Phase 1 は数えて表示するだけ
  maxCombo,
  cleared,         // クリアしたコマンド数
  inputs,          // 正しく押したキーの総数
  misses,
  command,         // 例: ['U','R','D']
  pos,             // 次に押す位置
  gauge,           // 連続クリア数（0〜GAUGE_MAX-1。ミスで0）
  boosts           // 時間が増えた回数
}
```

## 5. ゲームの流れ

1. **ready**: 中央に「矢印キー／ボタンでスタート」。最初の方向入力（どの方向でも）でスタートする。その入力はコマンドの1文字目としては扱わない
2. **playing**: 60秒間。コマンドを順に入力する
3. **result**: 時間切れになったら結果を表示（SCORE・INPUTS・MISS・MAX COMBO・ACCURACY）と大きな `RETRY`
   - RETRY は Enter／Space／タップで押せる。押したら ready を挟まず **即 playing** で始まる
   - 時間切れ直後の連打で誤って RETRY しないよう、結果表示から **0.6秒** は入力を受け付けない

## 6. ルール（Phase 1 の初期値。遊んでから調整する）

すべて `10-logic.js` の先頭に定数としてまとめる。

| 定数 | 初期値 | 意味 |
|---|---|---|
| `TIME_LIMIT` | 60000 ms | 制限時間 |
| `LEN_START` | 2 | 最初のコマンドの長さ |
| `LEN_STEP` | 5 | 何コマンドクリアごとに1個長くなるか |
| `LEN_MAX` | 9 | 長さの上限 |
| `PTS_PER_KEY` | 100 | 矢印1個あたりの基本点 |
| `GAUGE_MAX` | 10 | 何コマンド連続クリアで満タンか |
| `GAUGE_BONUS` | 3000 ms | 満タンで増える時間 |
| `MISS_PENALTY` | 50 | ミス1回の減点 |

- **長さ** = `min(LEN_START + floor(cleared / LEN_STEP), LEN_MAX)`
- **コマンド生成**: 各文字を4方向から一様ランダムに選ぶ。同じ方向の連続も許す。乱数関数は引数で差し替えられるようにする（検証用）
- **正解キー**: `pos` を進め、`inputs` を+1。最後まで入力したらクリア
- **クリア時**: 
  - 得点 = `PTS_PER_KEY × 長さ`（速さによる加点はない）
  - `score += 得点`、`cleared += 1`、`combo += 1`、`maxCombo` を更新
  - **ゲージ**: `gauge += 1`。`GAUGE_MAX` に達したら `gauge = 0`、終了時刻を `GAUGE_BONUS` ぶん延ばし（残り時間 +3秒）、`boosts += 1`
  - **同じ処理の中で** 次のコマンドを生成して表示する（待ち時間ゼロ）
- **ミスキー**: `misses += 1`、`combo = 0`、`gauge = 0`、`score = max(0, score − MISS_PENALTY)`。**`pos` はそのまま**で続行
- **ACCURACY** = `inputs / (inputs + misses)`（両方0なら 100%）。小数点以下切り捨ての%表示
- 制限時間が0になった瞬間に入力中のコマンドは破棄し、result へ移る

## 7. 画面

- 上部 HUD: `SCORE` / `TIME`（小数1桁、残り10秒で色を変える）/ `COMBO`
- HUD の下に細い**時間ゲージ**（高さ6px）。連続クリア数に応じて伸び、満タンで空に戻る。満タン時は TIME の数字が緑に光って拡大し、横に `+3s` が浮かんで消える（中央のコマンドには重ならない位置）
- 結果画面に `TIME BONUS`（延びた合計秒数、例 `+6s`）を `MAX COMBO` の下に表示する
- 中央: コマンドを大きく表示する。入力済みは薄く、**次に押す1個を強調**する。9個でもスマホの縦画面で1行に収まる大きさに自動で縮める
- 正解・ミスの最低限のフィードバック: 正解した矢印が一瞬光る／ミスで次の矢印が赤く揺れる（0.15秒程度。次のコマンドを隠さない）
- 下部（タッチ端末のみ表示）: ↑↓←→ の十字ボタン
  - `pointerdown` で反応（`click` の遅延を避ける）
  - `touch-action: manipulation` などでダブルタップ拡大・スクロールを止める
  - タッチ端末の判定は `matchMedia('(pointer: coarse)')`
- キーボード: 矢印キーと WASD（W=↑ A=← S=↓ D=→）の両方で入力できる。矢印キーでページがスクロールしないよう `preventDefault`。押しっぱなしのキーリピートは無視する（`e.repeat`）

## 8. 音（Phase 1 は最小限）

- 正解キー: 短い「ピッ」
- コマンドクリア: 少し高い音
- ゲージ満タン（時間延長）: 上昇する2音のチャイム
- ミス: 低い音
- 終了: 短い結果音
- AudioContext は最初のユーザー入力で生成・resume する（ブラウザの自動再生制限）

## 9. 検証（verify.html）

`10-logic.js` だけを読み込んで、次を自動で確かめる:
- 長さの計算（クリア数 0／4／5／35／100 での長さ）
- 乱数を固定したときのコマンド生成
- 正解・ミス・クリア時の状態変化（`pos` がミスで動かないこと、スコアが0未満にならないこと）
- スコア計算（基本点×長さ）
- ゲージ（10連続クリアで +3秒・空になる／ミスで0に戻る／延長した分だけ時間切れが遅れる）
- ACCURACY の計算（0除算を含む）
